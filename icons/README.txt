App icon
========

icon.svg draws the character 习 (xí, to practise) in a 田字格. The character's outlines are the
stroke paths of 习 from the animCJK project (https://github.com/parsimonhi/animCJK,
graphicsZhHans.txt, commit c63765b), which are derived from the Arphic KaiTi fonts and licensed
under the Arphic Public License (the same licence as the KaiTi font in fonts/, see
fonts/LICENSE-ukai.txt). The icon is therefore a modified version of that data, made on
2026-11-15, and is freely available in this public repository.

The PNG files are rendered from icon.svg by `node tools/make-icons.mjs`.
